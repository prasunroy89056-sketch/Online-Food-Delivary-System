📖 About the Project

The Online Food Delivery System provides users with an intuitive interface to explore food categories, browse restaurant menus, view item pricing, and place food orders seamlessly from both desktop and mobile devices.

✨ Key Features

Responsive Web Design: Built with a mobile-first approach so the layout adapts smoothly across desktops, tablets, and smartphones.

Interactive Menu Showcase: Displays food items with high-quality images, descriptions, and clear pricing.

Cart & Order Management: Allows users to select items, update quantities, and review their order summary dynamically.

User-Friendly Navigation: Clean header, smooth scrolling sections, and straightforward order/contact forms.

🛠️ Technologies Used

HTML5 – Semantic page structure and content layout

CSS3 – Custom styling, animations, and visual design

Bootstrap 5 – Responsive grid system and pre-built UI components

JavaScript (ES6) & jQuery – DOM manipulation, interactive cart/order logic, and form validation

Tools: Visual Studio Code (VS Code), Git & GitHub
